# 사용자 Quick Guide (1 page)

## 시작
- 처음: **신규 사용자 등록** → 사번 · 이름 · 소속 입력 → 시작 (비밀번호 없음)
- 다음부터: **이 사용자로 시작** (공용 PC에서는 **사용자 변경**)

## 결함 등록 (1분)
`+ Issue 등록` → **결함** → 다섯 가지만 입력
1. 어디에서 발생했나요? (예: 고객관리 > 고객정보 조회) + 발생 환경
2. 어떤 문제가 발생했나요?
3. 어떻게 하면 다시 발생하나요? (단계별, 1단계 이상)
4. 정상이라면 어떻게 되어야 하나요?
5. 화면 캡처/증적 (선택)

조치자와 Priority는 입력하지 않습니다. 등록되면 `DEF-0023` 같은 ID가 생깁니다.

개선요청(`IMP-`)과 문의(`INQ-`)는 대상 + 내용만 입력합니다.

## 조치 (조치자)
- Kanban/목록에서 **미지정** Issue의 **[내가 조치]** → 나에게 배정 (Priority 지정 안내)
- Issue 상세에서 **[조치 시작]** → In Progress
- 작업 후 **[조치 완료]** → 처리 결과 (+ Change Reference, 반영 버전) → Done
- 배포 후 **[배포 완료]** → 환경/버전/일시 기록
- 등록자 확인이 어려우면 **[Close]** → 고객/업무담당자 확인·합의 내용 필수

## 재검증 (등록자)
- MY > **확인대기** 탭에 Done Issue가 모입니다
- 정상: **[정상 확인 · Close]** / 재발: **[재조치 요청]** (사유 필수) → 다시 In Progress

## Comment
상세 화면 하단에서 언제든 작성 (파일 첨부 가능). 수정/삭제는 없고 정정은 새 Comment로 남깁니다. 시스템 이력과 함께 Timeline에 시간순으로 표시됩니다.

## 찾기
- 상단 검색: ID, 제목, 현상, 등록자, Comment
- Kanban Quick Filter: 전체 / 신규·미지정 / 내가 등록 / 내가 조치 / 확인대기 / Critical
- MY: 내가 등록 / 내가 조치 / 확인대기

## 충돌 안내가 보이면
"다른 사용자가 먼저 수정했습니다" → **[최신 내용 불러오기]** 후 다시 시도. 입력 중이던 내용은 유지됩니다.
